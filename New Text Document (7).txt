Here’s a clear, practical explanation of funnel size by stage, conversions, and conversion rates between stages, using business + analytics language you can also use in your portfolio.

1️⃣ Funnel Size by Stage
What it means
The number of unique users/customers who reach each step of your funnel.

Example funnel stages

Visit / Signup

Product Viewed

Added to Cart

Checkout Started

Purchase Completed

Example funnel size

Stage	Users
Signup	10,000
Product View	7,500
Add to Cart	4,000
Checkout	2,500
Purchase	2,000
👉 This shows where people drop off.

2️⃣ Conversions Between Stages
What it means
How many users successfully move from one stage to the next.

Example

7,500 users viewed a product

4,000 added to cart

➡️ Conversions from View → Cart = 4,000 users

3️⃣ Conversion Rate Between Stages
Formula

Conversion Rate = (Users at Next Stage / Users at Current Stage) × 100
Example calculations

From → To	Users	Conversion Rate
Signup → View	7,500 / 10,000	75%
View → Cart	4,000 / 7,500	53%
Cart → Checkout	2,500 / 4,000	62.5%
Checkout → Purchase	2,000 / 2,500	80%
4️⃣ Overall Funnel Conversion Rate
What percentage of users complete the full journey?

Overall Conversion = Final Stage / First Stage
= 2,000 / 10,000 = 20%
👉 Only 20% of users who sign up actually purchase

5️⃣ Why This Matters (Business Insight)
Largest drop-off tells you where to focus optimization

Low early-stage conversion → marketing / onboarding issue

Low late-stage conversion → pricing, trust, or checkout friction

Improves revenue forecasting

Identifies revenue leakage

Portfolio-ready explanation

Here’s Option 2: SQL version — clean, portfolio-ready SQL to calculate funnel size, conversions, and conversion rates between stages.

Assumed Table Structure
sales_events

column	description
customer_id	unique customer
stage	funnel stage (Signup, View, Cart, Checkout, Purchase)
event_date	date of event
1️⃣ Funnel Size by Stage (Unique Customers)
SELECT
    stage,
    COUNT(DISTINCT customer_id) AS users
FROM sales_events
GROUP BY stage
ORDER BY users DESC;
👉 Tells you how many customers reached each stage

2️⃣ Funnel Ordered by Stage
If stages are not naturally ordered, define them:

WITH funnel AS (
    SELECT
        stage,
        COUNT(DISTINCT customer_id) AS users,
        CASE stage
            WHEN 'Signup' THEN 1
            WHEN 'View' THEN 2
            WHEN 'Cart' THEN 3
            WHEN 'Checkout' THEN 4
            WHEN 'Purchase' THEN 5
        END AS stage_order
    FROM sales_events
    GROUP BY stage
)

SELECT *
FROM funnel
ORDER BY stage_order;
3️⃣ Conversion Rate Between Stages (Core Funnel Metric)
WITH funnel AS (
    SELECT
        stage,
        COUNT(DISTINCT customer_id) AS users,
        CASE stage
            WHEN 'Signup' THEN 1
            WHEN 'View' THEN 2
            WHEN 'Cart' THEN 3
            WHEN 'Checkout' THEN 4
            WHEN 'Purchase' THEN 5
        END AS stage_order
    FROM sales_events
    GROUP BY stage
)

SELECT
    stage,
    users,
    LAG(users) OVER (ORDER BY stage_order) AS previous_stage_users,
    ROUND(
        users * 100.0 / LAG(users) OVER (ORDER BY stage_order),
        2
    ) AS conversion_rate_pct
FROM funnel
ORDER BY stage_order;
Output Example
Stage	Users	Previous	Conversion %
Signup	10,000	NULL	NULL
View	7,500	10,000	75.00
Cart	4,000	7,500	53.33
Checkout	2,500	4,000	62.50
Purchase	2,000	2,500	80.00
4️⃣ Overall Funnel Conversion Rate
SELECT
    ROUND(
        COUNT(DISTINCT CASE WHEN stage = 'Purchase' THEN customer_id END)
        * 100.0
        /
        COUNT(DISTINCT CASE WHEN stage = 'Signup' THEN customer_id END),
        2
    ) AS overall_conversion_rate_pct
FROM sales_events;
