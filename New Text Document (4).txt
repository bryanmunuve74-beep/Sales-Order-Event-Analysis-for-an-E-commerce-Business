# Customer Funnel & Revenue Analysis

## Overview
This project analyzes customer behavior and sales performance using a simulated e-commerce dataset.
The goal is to understand funnel drop-offs, revenue trends, and data quality issues.

## Dataset
The project uses three datasets:
- customers.csv – customer information and acquisition channels
- orders.csv – order-level revenue and discounts
- funnel_events.csv – customer event and funnel activity

The dataset includes missing values, inconsistent date formats, and invalid records to simulate real-world data.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Analysis Performed
- Data cleaning and validation
- Date conversion and missing value handling
- Funnel conversion rate calculation
- Revenue and average order value analysis
- Data visualization using Matplotlib

## Key Insights
- The biggest customer drop-off occurs between add_to_cart and checkout
- Mobile users generate more events but convert less than desktop users
- Cleaning invalid records significantly impacts funnel metrics

## How to Run
1. Clone the repository
2. Install required libraries
3. Run the analysis notebook or script
